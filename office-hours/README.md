# الساعات المكتبية: تفعيل الحفظ (مرة واحدة، نحو 5 دقائق)

الساعات المكتبية تُحفظ في **Google Sheet في حسابك**، لا في ملفات الموقع، فلا يمسّها أي تحديث للموقع.
برنامج صغير (Apps Script) مرتبط بالجدول يستقبل ما يُدخله المدرسون ويعيده للموقع.

## الخطوات

1. افتح <https://sheets.google.com> وأنشئ جدولاً فارغاً، وسمّه مثلاً «الساعات المكتبية – جامعة البترا».
2. من القائمة: **Extensions ← Apps Script**.
3. احذف ما في المحرر، والصق محتوى الملف [`Code.gs`](Code.gs) كاملاً، ثم احفظ (Ctrl+S).
4. من الشريط الجانبي **⚙ Project Settings ← Script Properties ← Add script property**، أضف خاصيتين:
   | Property | Value |
   |---|---|
   | `SITE` | `https://marafah.github.io/uopstaff/` |
   | `ADMIN_EMAIL` | بريدك (مدير الموقع): يسمح لك بإدخال الساعات نيابةً عن أي مدرس |
5. **Deploy ← New deployment ← ⚙ ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - اضغط **Deploy**، وامنح الأذونات المطلوبة (قراءة الجدول، إرسال البريد، جلب قائمة المدرسين من الموقع).
6. انسخ رابط **Web app URL** (ينتهي بـ `/exec`) وضعه في `data/office_hours_config.json`:
   ```json
   { "api": "https://script.google.com/macros/s/…/exec" }
   ```
   (أو أرسله لي وأضعه أنا.)

## كيف يعمل

- **الإدخال:** في صفحة كل مدرس زر «أضف ساعاتك المكتبية». يُرسَل رمز من 6 أرقام إلى بريده الجامعي المسجّل في دليل الموظفين (لا يستطيع أحد الإدخال باسم غيره)، ثم يختار أوقاته على جدوله مباشرة (محاضراته محجوبة)، والمكان والطريقة وملاحظة. يبقى المتصفح موثوقاً 30 يوماً.
- **رابط مباشر للمدرس:** `instructor.html?id=…&oh=edit` (صفحة «الساعات المكتبية» تنسخه لكل مدرس لم يُدخل بعد).
- **العرض:** في صفحة المدرس (بطاقة، والجدول الأسبوعي، وسطر «الآن»، وأوقات الفراغ)، وفي طباعة صفحته وبطاقة بابه، وفي صفحة «الساعات المكتبية» (حسب الكلية والقسم، تصدير Excel، طباعة مع QR).

## ضمان عدم ضياع البيانات

| الطبقة | ماذا تحمي |
|---|---|
| الجدول نفسه | منفصل تماماً عن ملفات الموقع؛ لا يمسّه أي تحديث للموقع. |
| ورقة «السجل» | كل حفظ يُضاف إليها ولا يُحذف؛ أي نسخة سابقة يمكن استعادتها. |
| سجل إصدارات Google | File ← Version history: كل حالة سابقة للجدول. |
| نسخة الموقع كل ساعة | `scripts/update_office_hours.py` ينسخ الساعات إلى `data/office_hours.json` في المستودع؛ يعرضها الموقع إن تعذّر الوصول إلى الخدمة. |
| مسودة المتصفح | ما يُدخله المدرس يُحفظ في متصفحه أثناء الكتابة؛ إغلاق الصفحة أو انقطاع الاتصال لا يُضيّعه. |

## ملاحظات

- إرسال البريد من حساب Google المجاني محدود بنحو 100 رسالة يومياً، وهو أكثر من كافٍ (رسالة واحدة لكل مدرس كل 30 يوماً).
- عند تعديل `Code.gs` لاحقاً: **Deploy ← Manage deployments ← ✎ ← Version: New version** (يبقى الرابط نفسه).
